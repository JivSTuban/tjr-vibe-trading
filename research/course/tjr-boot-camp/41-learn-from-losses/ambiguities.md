- **Entry-confluence requirement vs L36 retrace ladder tension.** L41 says an HTF BOS against your bias means "adapt and switch," but L36 says a LTF BOS opposing HTF bias is just a retrace (don't flip). The rule hinges on WHICH timeframe the opposing BOS is on — "high time frame" is not pinned to a specific TF here. Must reconcile the two lessons before coding a bias-flip rule.
- **"Equilibrium entry" not precisely defined.** He lists "order block + fair value gap + equilibrium entry" as a confluence but does not say equilibrium of which leg (50% of the impulse? of the range?). L36 defines equilibrium as 50% generally.
- **Daily loss cap number missing.** "Don't try to make back money" implies a stop-for-the-day rule but no number of losses / % drawdown is given.
- **Losing-streak threshold is soft.** "2-3 losing weeks" is approximate, not a hard trigger.
- **How many extra confluences.** He requires "extra confluence" beyond sweep+BOS but it's unclear if one (an OB OR FVG) is enough or if stacking multiple is expected.
