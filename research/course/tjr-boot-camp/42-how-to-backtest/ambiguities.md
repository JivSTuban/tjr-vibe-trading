# Lesson 42 — Ambiguities

- **No validation thresholds.** He says validate on live/demo but gives no number of trades, win-rate %, or sample size that constitutes a passing backtest/forward-test. A human must set the promotion gate.
- **"Random day" start point** for target practice is unstructured — no rule for sampling representative periods (trending vs choppy, session, news vs no-news). For an unbiased engine backtest, sampling must be deliberate (across regimes), which TJR does not address.
- **Human-vs-machine relevance.** His central objections to bar replay are (a) look-ahead of completed HTF candles and (b) missing emotion. For an automated engine, (a) is critical and directly actionable (no-look-ahead), while (b) is largely irrelevant (no emotion). This reframing is codex interpretation, not TJR's statement.
- **No numeric parameters** (no %, R:R, session/kill-zone times, lot math) in this lesson — methodology only.
