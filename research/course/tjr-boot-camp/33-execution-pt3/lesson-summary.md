# Boot Camp Day 33: Execution pt.3 — Summary

Lesson slug: `execution-pt3` | video: https://youtu.be/K8DwhtmvAW8 | duration 1441s

This is the third execution lesson. TJR's stated purpose: "putting all the pieces together"
[01:43]. It is largely a chart-walkthrough drill — cycling through many historical
examples of the same repeating entry model — rather than introducing new building blocks.
The one new addition is layering **equilibrium** onto the existing model [13:53].

---

## What TJR teaches (source layer)

### The core entry model (repeated all lesson)
TJR names the exact sequence multiple times up front [01:49]–[02:16] and again [06:31]–[06:46]:

1. **Liquidity sweep** — price takes out a prior low/high (liquidity) [06:48].
2. **Break of structure (BOS)** — price breaks structure in the intended direction
   ("broke structure to the upside on the 15 minute") [06:55].
3. **Fair value gap (imbalance) OR order block = the entry** [07:04].
   - He is explicit these are two entry variants of the same model:
     "this was not an order block entry, this was a fair value Gap entry" [07:14].
4. **Price returns and fills the imbalance / taps the order block, then rallies** [08:18],
   [11:35].
5. **Target = previous draws on liquidity** (prior highs/lows) [08:28], [10:02], [10:53].

He frames the FVG-entry variant as:
`liquidity sweep → break of structure → fair value gap entry` [07:04], and the OB-entry
variant as `liquidity sweep → break of structure → order block → (BOS again) → imbalance`
[12:03]–[12:12].

### Confirmation / execution mechanics
- **Scale down to a lower timeframe to find confirmation** for the entry [07:26], [09:44].
- Confirmation itself is often a **break of structure on the 15-minute** (or lower TF)
  at the point of entry [09:52], [10:02].
- **Entry trigger:** "we're gonna close above / execute" — i.e. act on the lower-TF BOS
  close [10:02].
- Stop loss placement is mentioned only loosely — "you put your stop loss like I don't
  know under this low or under these lows, we haven't covered that yet" [07:35]. SL/TP
  are deferred to future lessons [18:02].

### Adding equilibrium (the new layer)
- After covering the base model, he introduces **equilibrium** as an added confluence
  [13:53]–[14:12]: same model, "but we're just drawing equilibrium onto it."
- **Trigger to draw equilibrium:** "when you start seeing a retracement candle, when you
  see a down candle, I'm instantly looking for equilibrium" [14:52].
- **High-confluence condition:** equilibrium level **matching up with the fair value gap**
  — "where's our equilibrium matching up perfectly with our fair value Gap... that's a
  high Confluence trade" — enter there [15:00]–[15:18].
- Equilibrium is measured across the leg: "measuring from the low up until here" [16:27],
  and for a FVG, "measure it from swing low to the swing high" (he corrects himself: swing
  high to swing low) [19:54]–[20:13].
- **Equilibrium and fair value gaps are framed as "last chance entries"** [19:14].

### Stacking confluences
- On a strong example he counts confluences explicitly: price wicks into equilibrium
  [22:25], into the **5-minute order block**, into the **5-minute fair value gap** [22:45],
  plus BOS — "one confluence, two, three, four... break of structure is a confluence, seven
  confluences" [22:56]. Message: more overlapping confluences = higher-confidence trade.

### Daily-bias caveat (forward reference)
- Setups must align with **daily bias**: "if it's not in line with where we think market's
  going to go long term, odds are that run will be relatively short-lived... that move might
  not hit your first take profit" [23:36]–[23:53]. Daily bias is the next lesson's topic.

## Codex interpretation (inference layer — NOT stated verbatim by TJR)

- **codex_interpretation:** The lesson defines a single reusable long-setup template that
  can be inverted for shorts (he shows mostly bullish examples; the down-move example at
  [09:13]–[09:30] implies the symmetric bearish version). TJR never explicitly states the
  short-side rules, so the inversion is inferred.
- **codex_interpretation:** "Draws on liquidity" as the take-profit target maps to standard
  SMC — targeting opposing/prior liquidity pools. TJR uses the term but defers formal TP
  rules to a later lesson, so exact TP levels are not machine-specifiable from this lesson.
- **codex_interpretation:** "Equilibrium matches the FVG" likely means the 50% retracement
  level of the measured leg overlaps the FVG's price band; TJR shows it visually but gives
  no numeric tolerance for "matching perfectly," so a tolerance band would need to be
  chosen (see verification questions).
- **codex_interpretation:** The confluence count [22:56] is illustrative/hype, not a scored
  threshold; TJR does not state a minimum number of confluences required to trade.
